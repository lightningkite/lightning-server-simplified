# Lightning Server Simplified

TypeScript types and client utilities for [Lightning Server](https://github.com/lightningkite/lightning-server), a Kotlin backend framework.

SDKs generated by Lightning Server's TypeScript generator import their shared types (`Condition`, `Modification`, `Query`, `Fetcher`, `Brand`, ...) from this package.

## Installation

```bash
npm install @lightningkite/lightning-server-simplified
```

## Fetchers

A `Fetcher` sends requests to the server. Pass one to a generated SDK.

```typescript
import { createBasicFetcher, createBulkFetcher } from '@lightningkite/lightning-server-simplified';

// One HTTP request per call.
const fetcher = createBasicFetcher('https://api.example.com', async () => ({
  Authorization: `Bearer ${token}`,
}));

// Batches calls made within `delayMs` into one POST to `${serverUrl}/meta/bulk`.
const bulkFetcher = createBulkFetcher({
  serverUrl: 'https://api.example.com',
  headerCalculator: async () => ({ Authorization: `Bearer ${token}` }),
});
```

## Conditions and Modifications

`Condition<T>` and `Modification<T>` mirror the server's JSON format. Each one is an object with a single key: either an operator or a field name.

```typescript
import { Condition, Modification } from '@lightningkite/lightning-server-simplified';

const condition: Condition<User> = {
  And: [
    { name: { StringContains: { value: 'jo', ignoreCase: true } } },
    { age: { GreaterThanOrEqual: 18 } },
    { tags: { CollectionAnyElements: { Equal: 'admin' } } },
  ],
};

const modification: Modification<User> = {
  Chain: [
    { name: { Assign: 'Jane' } },
    { loginCount: { Increment: 1 } },
    { tags: { SetAppend: ['verified'] } },
  ],
};
```

| | Operators |
|---|---|
| Any condition | `Always`, `Never`, `And`, `Or`, `Not`, `Equal`, `NotEqual`, `Inside`, `NotInside`, `GreaterThan`, `LessThan`, `GreaterThanOrEqual`, `LessThanOrEqual`, `IfNotNull` |
| String | `StringContains`, `RegexMatches` (unanchored) |
| Int | `IntBitsClear`, `IntBitsSet`, `IntBitsAnyClear`, `IntBitsAnySet` |
| Array | `CollectionAllElements`, `CollectionAnyElements` (`List*`/`Set*` aliases also accepted) |
| `GeoCoordinate` | `GeoDistance` (`greaterThan` / `lessThan` in meters) |
| Any modification | `Nothing`, `Assign`, `Chain`, `IfNotNull`, `CoerceAtMost`, `CoerceAtLeast` |
| Number | `Increment`, `Multiply` |
| List | `ListAppend`, `ListRemove`, `ListRemoveInstances`, `ListPerElement` |
| Set | `SetAppend`, `SetRemove`, `SetRemoveInstances`, `SetPerElement` |

`evaluateCondition` and `evaluateModification` apply these locally, and `simplifyCondition` merges redundant clauses.

## Paths

`DataClassPathPartial<T>` is any dotted path into `T`. Use `?.` after a nullable field and `*` for array elements. `DataClassPath<T, V>` narrows that to paths whose value is a `V`. Sorting (`SortPart`), partial queries, and grouping all use these paths.

```typescript
const sort: SortPart<User>[] = ['-createdAt', '~name'];   // descending, case-insensitive
const groupBy: DataClassPathPartial<User> = 'address?.city';
const property: DataClassPath<User, number> = 'stats.score';
```

## Branded IDs

`Brand<K, T>` keeps IDs of different models from being mixed up.

```typescript
type UserId = Brand<string, 'User'>;
const id: UserId = asBrandedId('3f2c...');
```
